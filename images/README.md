# Nōvuu Medspa — Image Directory

All website images live here, organized by section. Reference images with relative paths from HTML files: `src="images/[folder]/[filename]"`.

|--------|----------|-------|

## Recommended File Formats

- **JPG** — photos (patients, procedures, staff, environments)
- **WebP** — JPG alternative with better compression (modern browsers only)
- **PNG** — product shots or images requiring transparency

## Tips

- Keep filenames lowercase with hyphens: `hero-homepage.jpg`, `dr-jane-smith.jpg`
- Use `loading="lazy"` on images below the fold
- Aim to keep individual files under 500KB for performance
