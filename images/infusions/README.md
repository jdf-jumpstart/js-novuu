# Infusion menu images

`infusions.html` references one IV-bag product image per menu item from this
folder. Drop the images here using these exact filenames (PNG):

| Menu item          | Filename                      |
| ------------------ | ----------------------------- |
| The Morning After  | `the-morning-after.png`       |
| Meyer's Cocktail   | `meyers-cocktail.png`         |
| Beauty Blend       | `beauty-blend.png`            |
| Immunity           | `immunity.png`                |
| Fly High Hydration | `fly-high-hydration.png`      |
| Vitality NAD+      | `vitality-nad.png`            |

These are the same IV-bag product images used on the original
novuumedspa.com infusions page. The cards display them at a 4:5 aspect ratio
with `object-fit: contain`, so any reasonable product-cutout image works.
